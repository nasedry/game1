## 1. Мета роботи

## 2. Опис доопрацьованого прототипу

### Рівні
Реалізовано два ігрових рівні (`GameScene` — Рівень 1, `GameScene2` — Рівень 2) з різними умовами:

| Параметр | Рівень 1 | Рівень 2 |
|---|---|---|
| Час (сек) | 60 | 45 |
| Коробок до перемоги | 10 | 15 |
| Швидкість гравця | 5 | 7 |
| Зірки (1★/2★/3★) | 4/7/10 | 6/10/15 |

### Конфігурація (ScriptableObject)
Створено клас `LevelConfig` (ScriptableObject). Для кожного рівня у папці `Assets/Resources` створено окремий asset (`Level1Config.asset`, `Level2Config.asset`). Параметри задаються в Інспекторі без редагування коду.

### HUD
- Лічильник доставлених коробок у форматі `Доставлено: X/N`
- Таймер у форматі `Час: MM:SS`
- Поточне завдання (колір коробки для доставки)
- Номер поточного рівня

### Вікна станів
- **Пауза** — викликається клавішею `Esc`; кнопки: Продовжити, Перезапустити, Головне меню
- **Перемога** — з'являється після доставки N коробок; кнопки: Наступний рівень (якщо є), Перезапустити, Головне меню
- **Поразка** — з'являється після закінчення таймера; кнопки: Перезапустити, Головне меню

### Головне меню
Сцена `MainMenu` з кнопками:
- **Грати** — запускає Рівень 1
- **Рівень 2** — запускає Рівень 2 безпосередньо
- **Вийти** — закриває застосунок

### Анімації
Компонент `UIAnimator` реалізує анімацію появи/зникнення панелей через `CanvasGroup` (alpha + scale) з `AnimationCurve`. Використовує `Time.unscaledDeltaTime` — працює під час паузи.

## 3. Перелік реалізованих елементів

### Скрипти (нові)
| Файл | Призначення |
|---|---|
| `LevelConfig.cs` | ScriptableObject з параметрами рівня |
| `PauseManager.cs` | Система паузи (ESC), кнопки Resume/Restart/MainMenu |
| `UIAnimator.cs` | Анімація появи/зникнення панелей UI (scale + alpha) |

### Скрипти (оновлені)
| Файл | Зміни |
|---|---|
| `GameManager.cs` | Підтримка `LevelConfig`, умова перемоги (`deliveriesToWin`), `NextLevel()`, `IsGameOver`, HUD номера рівня, зірки ★☆ |
| `PlayerMovement.cs` | Метод `SetSpeed(float)` для застосування швидкості з конфігу |

### HUD елементи
- `scoreText` — кількість доставок (X/N)
- `timerText` — таймер (MM:SS)
- `taskText` — поточне завдання
- `levelNumberText` — номер рівня

### Вікна станів
- `resultsPanel` — перемога або поразка (залежно від `isWin`)
- `pausePanel` — пауза
- `nextLevelButton` — умовно активна кнопка «Наступний рівень»

### Навігація між сценами
- `MainMenu` → `GameScene` (Рівень 1) → `GameScene2` (Рівень 2) → `MainMenu`
- ESC → пауза → Resume / Restart / MainMenu
- Перемога → Next Level / Restart / MainMenu

## 4. Опис системи рівнів

Система рівнів реалізована через окремі сцени Unity (`GameScene`, `GameScene2`). Кожна сцена має власний `GameManager` з прив'язаним `LevelConfig` asset.

**Потік рівнів:**
```
MainMenu → GameScene (Level 1) --перемога--> GameScene2 (Level 2) --перемога--> MainMenu
```

Кнопка «Наступний рівень» у вікні результатів активується лише при перемозі та якщо поле `nextLevelSceneName` у конфігу не порожнє.

## 8. Висновок

У результаті лабораторної роботи ігровий прототип Box Delivery отримав повноцінну демонстраційну структуру:

- Реалізовано **два рівні** з різними параметрами складності.
- Параметри рівнів **винесено в `LevelConfig` (ScriptableObject)** — швидкість гравця, час, кількість доставок для перемоги, рейтингові пороги.
- **HUD** відображає рахунок (X/N), таймер, завдання та номер рівня, оновлюється у реальному часі.
- Реалізовано **три вікна станів**: пауза (Esc), перемога (N доставок), поразка (таймер = 0).
- Навігація між сценами (MainMenu → Level1 → Level2 → MainMenu) працює коректно.
- **Анімація панелей** (scale + alpha) реалізована через `UIAnimator` без сторонніх бібліотек.
- Потребує вдосконалення: звукові ефекти, збереження прогресу (`PlayerPrefs`), більше рівнів, покращення анімації персонажа.
